# 3-minute demo video script

0:00-0:20  Problem: roads/bridges gone, rescuers need to know damage + who is cut off. Say "educational prototype".
0:20-0:50  Show the dashboard sidebar: enter AOI + date (judges' area) -> Run. (Pre-run one result so you are not waiting.)
0:50-1:30  Map: flood (blue water / brown debris), red roads and bridges hit, affected buildings. Click a village -> "cut off".
1:30-2:00  Cut-off table + hospital access + detour distances. Mention confirmed vs conservative scenarios.
2:00-2:25  AI component: held-out Himalayan IoU/F1 table vs baseline. One honest failure case.
2:25-2:45  Case study: EMSR927 comparison numbers (checking only, never input).
2:45-3:00  Limitations (no early warning, revisit time, layover/shadow, OSM completeness) + attributions on screen.
Do NOT show images of victims. Show the one-page PDF report (EN + Nepali) briefly.
